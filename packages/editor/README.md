# @clarusjs/editor

A rich-text editor for [clarusjs](https://clarusjs.com), on ProseMirror:

- **`<editor-composer>`**: a chat or comment composer to drop in. A plain textarea until it's focused, then an editor with mentions, slash commands, emoji and Enter to send.
- **Behaviours** (`editor`, `suggestion`, `toolbar`) for `[use]`, to build your own.
- **`@clarusjs/editor/server`**: `validate` and `renderHTML`, with no DOM.

See the [editor guide](https://clarusjs.com/guide/editor-composer).
