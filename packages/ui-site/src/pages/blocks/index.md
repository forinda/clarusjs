# Blocks

<p class="lead">Whole pages built from the components: a login, a checkout, a dashboard. Copy one into <code>src/pages/</code>, copy the components it lists into <code>src/components/ui/</code>, and it looks done and works. Then swap in your data and your submit.</p>

Each block keeps its sample data and its submit handler in a `data.ts` beside it: replace those, and nothing else needs changing. The blocks style themselves with your `theme.css`, so a theme from [the theme builder](/theme) restyles them too.
