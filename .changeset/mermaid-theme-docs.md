`mermaid.tscl`: draws Markdown's ```` ```mermaid ```` diagrams (`markdown({ mermaid: { tag: 'diagram', from: '@clarusjs/theme-docs/mermaid.tscl' } })`, with `mermaid` installed as an optional peer). Each diagram is drawn when it scrolls into view, after a navigation too, in the page's light or dark theme, and again when the theme changes; its source shows until then, or if it can't be drawn.
