Learning progress in the browser: `config.learn` (the Learn section and its progress page). Lessons record steps, finished lessons and first quiz answers in one versioned `localStorage` key; XP and badges are computed from it. An XP chip shows in lesson headers and Learn pages, the Learn sidebar marks lessons done / up next / not started, and `learn-progress.tscl` shows XP, lessons, quiz accuracy, badges and Reset. Blocked storage and no JavaScript degrade to plain pages.
