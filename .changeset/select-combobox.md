Select and Combobox (#466): `select.tscl`, a native `<select>` that's the customizable select (`appearance: base-select`) where the browser has it, with `[(value)]` and `(change)`; and `combobox.tscl`, the docs site's combobox moved into the package and made headless (`data-part` on each element, `data-highlighted` on the active option, only its list's positioning styled): one pick or several, options from the server, keyboard, and a `(change)` a parent can cancel.
