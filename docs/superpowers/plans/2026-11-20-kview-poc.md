# kview POC Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A page served by a Vite dev server, rendered on the server from `.kvw` files, where one `<counter>` is interactive in the browser and the only JS on the page is the island loader plus the counter's chunk.

**Architecture:** A TypeScript compiler (`parse → lower/check → IR → emit`) turns each `.kvw` file into either a server module (`render(props) → string`, with markers around reactive holes) or, for stateful components only, a client module (`attach(root, props)`). A Vite plugin picks the output per environment (`this.environment.config.consumer`), and a dev middleware runs a `fetch(Request)` handler loaded through `server.environments.ssr.runner.import()`.

**Tech Stack:** TypeScript (strict), Node ≥ 22, Vite 8, acorn, Vitest, happy-dom (tests only).

**Spec:** `docs/architecture.md` (sections 4–6, 10, 11, 14, 16 are in scope)

## Global Constraints

- Runtime dependency: `acorn` only. Dev dependencies: `vite@^8`, `vitest`, `typescript`, `happy-dom`, `@types/node`. Nothing else.
- Compiler is pure: `compile(source, options)` takes a string and returns a string. No `fs`, no Vite imports inside `src/compiler/`.
- Internal JS AST types are ESTree (acorn's output). No acorn-specific node fields.
- Compiled output is readable: no minification; static HTML chunks are emitted as `JSON.stringify(chunk)` joined with `+`.
- Every compile error is a `KviewError` whose message is `` `${file}:${line}:${column} ${text}` `` (1-based line and column).
- HTML contract (exact): island `<kv-island c="NAME" src="URL" p="JSON">…</kv-island>`; reactive hole `<!--[N-->…<!--]-->`; event element `data-kv-e="N"`. Static parts carry no markers.
- Client modules never import server modules (`render`, `kview/runtime/server`, loaders).
- A component without `<script>` is stateless: its client compile is `export {}` and nothing ever imports it on the client.
- Package imports used by compiled code: `kview/runtime` (browser) and `kview/runtime/server` (server). The plugin aliases these to `src/runtime/index.ts` and `src/runtime/server.ts`.

## Review Focus

1. User data containing HTML or quotes (`<script>`, `"`, `'`, `&`) in a text hole or an island prop: must render escaped, never as markup. Tests: Task 1 (`escape`, `island`), Task 6 (render with hostile input).
2. Static template text containing `` ` ``, `${`, `\` or `"`: must come out byte-identical. Test: Task 6.
3. A reactive hole whose initial value is empty (`''`, `null`, `undefined`): server emits `<!--[0--><!--]-->`, client still updates it later. Test: Task 7.
4. Two instances of the same island on one page: clicking one must not change the other. Test: Task 7.
5. One island's chunk failing to load or its `attach` throwing: the other islands still attach, and the error is logged with the island name. Test: Task 8.

### Task 3: Parser

**Files:**
- Create: `src/compiler/errors.ts`, `src/compiler/parse.ts`
- Test: `test/compiler/parse.test.ts`

**Interfaces:**
- Produces (`errors.ts`): `class KviewError extends Error { file: string; line: number; column: number; constructor(text: string, file: string, source: string, offset: number) }` — computes 1-based line/column from `offset`; `message` is `` `${file}:${line}:${column} ${text}` ``.
- Produces (`parse.ts`):

```ts
export type Attr =
  | { kind: 'static'; name: string; value: string | true; start: number }
  | { kind: 'event'; name: string; expr: string; start: number }   // (click)="..."
  | { kind: 'prop'; name: string; expr: string; start: number }    // [start]="..."
export type TemplateNode =
  | { type: 'element'; tag: string; attrs: Attr[]; children: TemplateNode[]; start: number }
  | { type: 'text'; value: string; start: number }
  | { type: 'expr'; expr: string; start: number }                  // {{ expr }}
export type InputDecl = { name: string; type: string; default?: string; start: number }
export type ImportDecl = { name: string; from: string; start: number }
export type ParsedFile = {
  inputs: InputDecl[]; imports: ImportDecl[]
  script?: { code: string; start: number }   // start = offset of first char inside <script>
  nodes: TemplateNode[]
}
export function parse(source: string, file: string): ParsedFile
```

Grammar (POC): `{{-- … --}}` comments are dropped. A line whose first non-space char is `@` at top level is a directive: `@input NAME: TYPE` with optional `= DEFAULT` (TYPE is the raw text up to `=` or end of line, trimmed), and `@import NAME from 'PATH'` (single or double quotes). One top-level `<script>…</script>` block, content kept raw. Elements with double-quoted attribute values, `/>` self-closing, and HTML void elements (`area base br col embed hr img input link meta source track wbr`) closing themselves. Whitespace-only text between top-level nodes is dropped; text elsewhere is kept as is.

Errors (`KviewError`, `offset` pointing at the problem): unclosed element (`<div>` with no `</div>`), mismatched close tag, unclosed `{{`, `{{ }}` inside an attribute value (text: `interpolation in attributes is not supported yet`), unknown directive (`@foo`), second `<script>` block.

### Task 4: Script analysis and signal rewrite

**Files:**
- Create: `src/compiler/script.ts`
- Test: `test/compiler/script.test.ts`

**Interfaces:**
- Consumes: `KviewError` (Task 3).
- Produces:

```ts
export type Signals = Map<string, 'state' | 'derived'>
export function analyzeScript(code: string, file: string, source: string, offset: number): Signals
export function rewriteClient(code: string, signals: Signals): string   // whole script
export function rewriteClientExpr(expr: string, signals: Signals): string
export function rewriteServer(code: string): string
export function referencesSignal(expr: string, signals: Signals): boolean
```

Rules:
- `analyzeScript`: every top-level `let|const NAME = state(…)` → `'state'`; `NAME = derived(…)` → `'derived'`. Parse with `acorn.parse(code, { ecmaVersion: 'latest', sourceType: 'module' })`; syntax errors become `KviewError` at `offset + err.pos`.
- `rewriteClient` / `rewriteClientExpr`: for identifiers naming a signal (not as a declaration id, not as a non-computed member property `.count`, not as an object key): read → `NAME.get()`; `NAME = v` → `NAME.set(v)`; `NAME++`/`++NAME` → `NAME.set(NAME.get() + 1)` (`--` likewise); `NAME op= v` → `NAME.set(NAME.get() op (v))`. `let NAME = state(` declarations become `const NAME = state(`.
- `rewriteServer`: `state(X)` → `(X)`; `derived(F)` → `(F)()`.
- Edits are applied by splicing on node `start`/`end`, last edit first. Walk the ESTree with a ~20-line recursive walker (no `acorn-walk`). Mark: `// ponytail: name-based rewrite ignores shadowing (a local named like a signal gets rewritten); add scope tracking with @for/nested functions in stage 2`.

### Task 5: Lower to IR, with checks

**Files:**
- Create: `src/compiler/ir.ts`
- Test: `test/compiler/ir.test.ts`

**Interfaces:**
- Consumes: `ParsedFile`, `InputDecl`, `ImportDecl` (Task 3); `Signals`, `analyzeScript`, `referencesSignal` (Task 4).
- Produces:

```ts
export type IRNode =
  | { kind: 'static'; html: string }
  | { kind: 'hole'; expr: string; reactive: boolean; index: number }  // index = -1 when not reactive
  | { kind: 'component'; name: string; props: { name: string; expr: string }[] }
export type IREvent = { index: number; type: string; handler: string }
export type ComponentIR = {
  file: string; name: string            // name = basename without .kvw
  inputs: InputDecl[]; imports: ImportDecl[]
  script?: string; signals: Signals; stateful: boolean
  nodes: IRNode[]; events: IREvent[]
}
export function lower(parsed: ParsedFile, file: string, source: string): ComponentIR
```

Rules: adjacent statics are merged. Static attributes are copied verbatim (`name="value"` or bare `name`). Each element with one or more `(event)` attrs gets one index (counting from 0 in document order), emitted as ` data-kv-e="N"`, with one `IREvent` per event attr. Reactive holes are numbered from 0 in document order. A tag is a component iff its name matches an `@import` name.

Check errors (`KviewError` at the offending `start`):
- `(event)` in a component with no `<script>` → `event bindings need a <script> with state; this component is static`
- `[prop]` on a non-component element → `[prop] bindings on HTML elements are not supported yet`
- a component tag with children → `slots are not supported yet`
- a component tag inside a stateful component → `components inside a stateful component are not supported yet`
